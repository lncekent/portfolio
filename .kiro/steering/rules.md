# Portfolio Project — Agent Rules

## Identity
- Personal portfolio of Lance Kent Geoffrey B. Magollado
- URL: https://lancekent.dev/
- Stack: React 19, Vite 8, Tailwind CSS v4, shadcn/ui, Lucide React

## Conventions
- JavaScript only (no TypeScript)
- Tailwind utility classes inline (no CSS modules)
- Components: PascalCase, functional with hooks
- All content data lives in `src/data.jsx`
- Do NOT modify `src/components/ui/` (shadcn primitives)
- Dark mode: class-based (`.dark` on `<html>`)

## Agent Behavior
- Explain problems before fixing — the user is learning
- Present options and let the user decide before applying changes
- Never break mobile/tablet responsive behavior (< 1024px)
- Prefer Tailwind patterns over custom CSS
- Keep changes minimal and focused
